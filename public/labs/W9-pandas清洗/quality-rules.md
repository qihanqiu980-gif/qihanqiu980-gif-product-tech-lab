# 数据质量规则 v1

| 规则 | 判断 | 处理 | 业务理由 |
|---|---|---|---|
| order_id 完整 | 非空 | 隔离 | 无法追溯订单 |
| order_id 唯一 | 同一 ID 只出现一次 | 全部重复行隔离 | 需要人工判断正确版本 |
| user_id 完整 | 非空 | 隔离 | 用户级指标无法去重 |
| status 有效 | paid / cancelled / refunded / pending | 隔离 | 未知状态无法进入既定口径 |
| paid_amount 有效 | 可转数字且非负 | 隔离 | 0 可以是业务值，空和负数不是同义 |
| paid_at 有效 | 可解析时间 | 非 paid 可保留空；paid 必须有效 | 支付分析需要时间边界 |
| channel 有效 | app / web / miniapp | 隔离 | 未知渠道需补映射表 |

任何规则变化必须更新版本，并重新输出受影响行数。
