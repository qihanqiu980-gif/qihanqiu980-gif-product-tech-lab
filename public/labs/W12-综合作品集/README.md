# W12 综合作品集资料包

目标不是堆砌页面截图，而是用证据完成一条可复核叙事：问题 → 方案 → 系统与数据 → 实验/评测 → 风险与兜底 → 结果与反思。

## 最低交付

- `project-brief.md`：问题证据、目标、非目标、约束和最大未知。
- `system-and-data.md`：系统链路、API、数据表/埋点、权限与状态机。
- `validation-log.csv`：每次 SQL、Python、接口或 AI 评测的输入、结果和证据路径。
- `risk-register.csv`：风险、概率、影响、监控、兜底与负责人。
- `portfolio-checklist.md`：10 分钟展示前自检。

所有真实工作案例必须脱敏；不要放公司 Token、生产地址、源码和个人隐私。
