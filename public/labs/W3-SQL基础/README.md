# W3 SQL 基础实验：新人券订单查询

本资料全部为教学模拟数据。目标不是背语法，而是把业务问题翻译成可复现的查询，并留下口径和对账证据。

## 运行环境

macOS 已内置或可安装 SQLite。先在终端进入本文件夹，然后运行：

```bash
sqlite3 w3_lab.db < setup.sql
sqlite3 -header -column w3_lab.db < exercises.sql
```

`exercises.sql` 是可修改的练习起点。先复制书面记录模板：

```bash
cp notes-template.md notes.md
```

完成 SQL 和 `notes.md` 后，运行一键自检：

```bash
sh self_check.sh
```

自检会重新建立临时数据库，执行你的 `exercises.sql`，检查固定命名结果视图的行数、去重数、金额和分组结果，并确认 SQL 中没有遗留 `TODO`、`notes.md` 的 10 个必填字段都已填写。临时数据库会自动删除，不会覆盖 `w3_lab.db`。

自检通过后再用 `answers.sql` 对照写法；不要在独立完成前复制答案。

## 12 个任务

1. 查看 10 行样本并说明“一行代表什么”。
2. 找出 2026-08-31 当天全部已支付订单。
3. 排除测试订单。
4. 只保留使用新人券的订单。
5. 按支付时间倒序输出。
6. 统计支付订单行数。
7. 统计去重支付用户数。
8. 计算支付金额。
9. 对比 `COUNT(*)` 与 `COUNT(DISTINCT order_id)`。
10. 找出金额为空或非正数的异常记录。
11. 按渠道统计订单数和金额。
12. 写出结果能够支持与不能支持的结论。

## 完成证据

- 保存你修改后的 `exercises.sql`。
- 截图或复制 `sh self_check.sh` 的全 PASS 结果。
- 提交填写完成的 `notes.md`，写清时间范围、状态、测试数据、退款和去重规则。
- 不要把“相关”写成“因果”，不要因查询为 0 就直接宣布业务为 0。
