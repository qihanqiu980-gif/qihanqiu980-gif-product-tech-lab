# 阶段 04：接口契约与异常验收

## 功能

W6 在 W1 HTTP 前置上首教字段类型、必填/可选、枚举、空值、默认值、未知字段、错误结构、超时和兼容；使用 `W6-API契约`，区分本地 payload 校验与真实服务行为，产出可评审契约/字段问题单。

W7 首教权限矩阵、资源状态、幂等、并发冲突、分页、限流和降级；使用 CSV/XLSX/模拟器，学习者新增独立场景，产出包含预期/实际/证据/风险/责任人的验收矩阵。

## 验收

W6D1–W7D6 全部 available，累计 42；非法 payload 被拒绝，CSV/XLSX/模拟器一致，能区分 401/403、状态冲突、重复提交、限流和服务失败；全量门禁与构建通过。
