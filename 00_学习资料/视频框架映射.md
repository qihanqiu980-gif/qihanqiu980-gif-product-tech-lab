## 映射到产品经理技术课程

统一的完整周课程顺序：

1. 为什么学：对应真实产品工作和本周决策。
2. 概念关系：用因果链说明新知识与已有能力的关系。
3. 核心机制：提出三个需要穿透的问题和四层知识结构。
4. 实时观察器：调整 3–5 个业务或技术变量，立即观察数据、状态、风险和结论变化。
5. 产品案例：用教学脱敏场景说明背景、冲突、证据和产品决策，不把案例包装成未经提供的真实公司经历。
6. 代码实验：下载本周资料包，按六步操作获得可复现证据。
7. 快速自测：每周 10 道即时选择题，答错进入同概念复训。
8. 本周只需要记住这些：5 条闭卷记忆锚点。
9. 下一步：说明本周能力怎样成为下一周输入。

## 12 周观察器映射

| 周次 | 页面内可调观察器 | 主要证据 |
|---|---|---|
| W1 | 请求链路追踪 | 当前节点、Network 状态、响应证据 |
| W2 | 故障注入 | 状态码、耗时、日志线索、恢复路径 |
| W3 | SQL 查询边界 | 返回行数、支付金额、去重用户、边界遗漏 |
| W4 | 指标口径 | 分子、分母、去重、窗口变化后的转化率 |
| W5 | JOIN 粒度 | JOIN 后行数、唯一订单、错误 GMV 与膨胀倍数 |
| W6 | API 契约 | HTTP 状态、业务 code、字段错误和恢复动作 |
| W7 | 幂等与并发 | 重复订单、冲突、限流、重试后的业务结果 |
| W8 | Python 数据处理 | 已处理、异常、跳过、汇总金额与运行结论 |
| W9 | 数据清洗 | clean、quarantine、丢失行、规则命中与审计性 |
| W10 | A/B 实验健康 | SRM、有效样本、转化提升、投诉护栏与决策 |
| W11 | AI 评测 | 事实、任务、安全、延迟、通过率和兜底决策 |
| W12 | 作品集完整度 | 证据覆盖、可复现性、风险覆盖和展示准备度 |

## 不照搬的部分

- 不照搬视频的深色主题；当前课程需长时间阅读，沿用更清晰的工程纸面视觉。
- 不照搬深度学习知识与 GPU 环境；课程内容仍服务产品经理的研发沟通、数据分析、需求评审和 AI 产品能力。
- 不把观察器的模拟结果包装成生产数据；页面继续明确标记“教学模拟”。
