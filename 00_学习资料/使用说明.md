# 学习资料使用说明

将新资料放入 `待同步`，同步成功后按版本归档到 `已同步`。

## 打开课程

1. 优先双击课程文件夹根目录中的 `index.html`。
2. 如果浏览器显示空白页，双击 `打开课程.command`，等待浏览器自动打开 `http://127.0.0.1:4317`。
3. 使用启动脚本时，请保留弹出的终端窗口；关闭窗口后，本地课程服务也会停止。
4. 学习进度保存在当前浏览器中。W1D1 请使用日课页顶部的“备份完整证据 JSON”和“恢复 W1D1 证据”；恢复前会请求确认，只替换 W1D1、保留其他 Day，检测到不安全的跨日引用时会拒绝恢复。“进度”页工具目前只处理旧课程 v1 历史档案。
