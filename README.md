面向零技术基础产品经理的交互式技术教材。当前正在按“概念讲解 → 完整示范 → 引导实操 → 独立练习 → 反馈纠错 → 间隔复习 → 工作迁移”重构全部 12 周课程。

W1D1 是冻结内容质量基准；W1D2–W1D5 已按正式 Day 01 可见工作台重做为各自独立的两时段七章课程，当前真实可用范围为 5/72。Day 05 专门教授浏览器 Network 请求条目、详情字段、Timing／Size／缓存线索与有限证据记录。旧周课页仍只作为历史素材；W1D6–W12D6 未完成前不会被旧提纲冒充为教材。

全项目当前真实覆盖率可用 `npm run audit:course-inventory` 查看：内容注册、已审核实现与真正可学习数量分开统计，不会把旧提纲或只有数据、没有领域实验的 Day 计作完成。开发阶段用 `npm run validate:all` 执行类型、证据、目录、W1D1、离线单文件、旧路径、启动脚本、实验包和下载路径门禁；只有 72/72 内容和实现都完成后，`npm run build:release` 才会放行正式发布构建。需求与依赖审计见 `00_学习资料/全项目验收矩阵.md`、`00_学习资料/72日课程盘点与依赖审计.md`。

日课路由现在由权威注册表驱动：`npm run validate:day-routes` 会遍历并往返验证全部 72 个 `#/lesson/WnDn` 地址。当前结果诚实区分为 5 个可学习 Day、0 个实现缺失 Day 和 67 个内容缺失 Day；W1D1–W1D5 可提前观看，不读取前一天完成状态，未完成 Day 仍显示明确质量门槛。新增课程还必须通过 `npm run validate:course-catalog`：除概念级自依赖、同日未来依赖、跨日未来依赖与首次教学冲突外，还会检查 Day 编号、下一课顺序、局部/全局 ID、概念是否进入后续证据任务、30/45 分钟路径是否漏掉引导实验，以及概念正文、示范、实验、成果、复习和练习是否只是复制后替换术语。

实现注册表保存可执行对象而不是字符串占位：已审核 Day 必须同时绑定可加载的 Vue 渲染器、可执行实验契约和 v2 证据契约，并通过 `npm run validate:course-implementations`。生产构建将动态日课渲染器折叠回单个脚本，再把脚本、样式和 101 个字体子集内嵌到根目录 `index.html`；`npm run validate:offline-single-file` 会阻止外部运行资源、模块加载残留或旧路径重新进入双击入口。实验资料仍作为可下载附件保存在 `dist/labs`。

## 启动

最简单的方式：双击 `index.html`。入口已经把课程脚本和样式内嵌到单个页面中，避免 Chrome 对 `file://` 外部资源的限制。

如果浏览器仍限制本地文件功能，macOS 可双击 `打开课程.command`（或 `start-course.command`）。启动器默认使用固定端口 `4317` 并打开内嵌资源入口；如端口被其他程序占用，会明确提示而不会静默换端口，以免浏览器学习记录分散。需要覆盖时可显式设置 `COURSE_PORT`。当根目录 `index.html` 与 `dist/index.html` 都存在且不落后于源码时，启动课程不需要联网或重新安装依赖；否则脚本会尝试重新构建，缺少 `node_modules` 时才执行安装。也可以在终端运行：

```bash
npm install
npm run dev
```

开发模式使用固定端口 `4317`；开发入口为 <http://127.0.0.1:4317/course-source.html>，单文件及启动脚本入口为 <http://127.0.0.1:4317/index.html>。固定来源可避免浏览器把学习记录分散到不同端口。

学习状态保存在当前浏览器中。W1D1 请在日课页顶部使用“备份完整证据 JSON”和“恢复 W1D1 证据”；恢复前会确认，只替换 W1D1 并保留其他 Day。“进度”页可导出全局 v2 证据账本；页面下方单独标注的导出、导入和清空工具只处理旧课程 v1 历史档案。

复盘页顶部已经接入两个 v2 工作台：待审核证据工作台逐项审核闭卷解释、独立变式、今日成果和工作迁移；真实复测执行台处理 D1/D3/D7/D14/D30/D60。审核只追加结论，不改写原始提交；修订会新增版本并保留历史。D1/D3 只证明短期间隔回忆，不满足 L3 长期保持门槛。

“概念”入口不是旧式词典，而是由完整日课注册表生成的索引：显示首次教学 Day、本课前置、完整定义、易混边界、本课实验、错题、当前证据与下一次复习。当前只展示真正完成的 W1D1–W1D5 概念，不会把其余 67 Day 的旧提纲伪装成已学内容。
